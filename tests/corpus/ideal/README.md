# tests/corpus/ideal/ — 人工理想标注（O-06 / C-31）

`expected/` 基线是**程序产物**（golden 重烤自啮合，C-31）：对它算 F1 只能
监控回归漂移，不能度量「转换得好不好」。本目录存放**人工理想标注**——
每个样本对应一份 `<样本名>.md`，由人对照源文件逐段核对后手写，是
质量指标的参照真值。

## 口径（双口径纪律）

| 参照系 | 用途 | 不得用于 |
| --- | --- | --- |
| `expected/`（程序基线） | 回归漂移监控（重烤前后 F1 应为 1.0） | 质量结论 |
| `ideal/`（人工标注） | 质量度量（`char_f1` / `heading_pr`） | 回归断言（标注会随方案演进修订） |

计算入口：`doc2md/qa_eval.py` 的 `char_f1`（字符级）/ `heading_pr`（标题，
DOCX 样式真值）/ `pred_headings`（IR blocks → pred 形态）。两者必须分开报告。

## 首批标注（N-3，2026-10-22）

## 标注规则

1. 一样本一文件，命名与 `sources/` 样本同名（`pdf_01.pdf` → `pdf_01.md`）。
2. 只标注「源文件里确实存在的信息」：页眉页脚、重复水印等家具不进标注
   （剔除是正确行为，不是偏差）。
3. 结构（标题层级/列表/表格）按人的阅读意图标注，不受当前管线能力限制
   ——标注是「目标」，管线是「逼近」。
4. 标注修订须在本文件追加一行变更记录（日期 + 样本 + 原因）。
