# 对照表：测试文档预期 — 目标理想结果 — 实际转换结果

- 数据来源：《功能测试文档》（`test-plan.md`）本轮实测记录
- 偏差类型定义：
  - **功能缺失** —— 契约或用户合理期待的能力不存在；
  - **逻辑错误** —— 能力存在但计算结果/保真度不正确；
  - **结构或格式差异** —— 内容不丢但组织结构/标记形式与理想 Markdown 有差别；
  - **兼容性与性能问题** —— 环境耦合、吞吐/驻留、跨平台行为不一致。
- 影响等级：**高**（误导用户或数据失真）/ **中**（系统性体验或质量判据受损）/ **低**（罕见、可容忍或有已知取舍）。
