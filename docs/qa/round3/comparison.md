## 1. 影响等级与偏差类型

| 等级 | 判定标准 | 处置口径 |
| --- | --- | --- |
| **高** | 破坏正文语义/文档结构，或把不可信内容带入下游渲染面；用户可感知「内容看不见」 | 阻断发布，P0 立即修复或产品决策 |
| **中** | 常见场景下结构或契约错误，调用方会误判 | 发布前修复或书面豁免 |
| **中低** | 边界路径错误，影响可感知但范围有限 | 与相关修复同批处理 |
| **低** | 可观测性、文档、结果行展示或度量口径问题，不影响转换结果 | 登记后排期 |

偏差类型沿用任务口径：**功能缺失、逻辑错误、结构或格式差异、兼容性与性能问题**。安全类问题归入「结构或格式差异」并标注安全影响。本册把「缺口」与「缺陷」分列：第 2 节的 N1–N4 是**缺口**——实际行为与既有文档口径一致，缺的是能力或裁定；第 2b 节的 HD-1/HD-2 是**缺陷**——实际行为违背既有承诺（内容损失 + 零告警）。分档判据见《测试文档》2.1，改判过程见第 6 节。

## 6. 对照结论

1. **主链路无回归**：核心 95 例中 92 例的「实际结果」与「测试文档预期」「目标理想结果」三者完全一致；第二轮 13 项偏差全部复验闭合，6 项错误码/告警缺口全部端到端补齐（错误码 14/14、告警 4/4，含 E4151 的 `password_required` 可与结构损坏区分）。
2. **本轮新增 2 项契约缺陷，且都是「损失无声」**：D02 跨页表整列脱落 + 裂成两张、D05 目录引导符成单元格 + `第一章 总则` 塌成 `第一章总则`，两者 `ir.warnings` 均为 0 条。它们违背的不是新约定，而是本轮已经宣称闭合的两条承诺——`W1045` 降维账本（deviation-analysis 3.3 写作「凡 S1 可见者均入账」）与文本保真。**这就是本册从「缺陷 0 / 不阻断」改判为「缺陷 2 / 阻断」的理由。**
3. **剩余问题的形态分三类，不再是一类**：核心面遗留 N1–N3 属「采集面不完整 + 判定开关与交付路径脱钩 + 探活契约条件可达」，需产品决策或外部样本；难度腿 HD-1/HD-2 属「真值来自源、产物不合规」，需改判据 + 人工逐页对照；N4（D08 层级）属真值侧口径未裁定，改哪一侧都要动 `content.md` 字节。
4. **本轮最大的收获在度量面而非功能面**：O-a…O-h 八项全部是「证据自己不成立」类问题——空跑断言、不严谨子串、混比口径、伪阶段、**结论前提未回文件复核**、**分档判据用反**、**骨架断言面窄于声明面**、**显示整数被当作事实继承**。八项没有一项是产品缺陷（O-h 甚至不改变任何指标档位），但每一项都足以让下一轮误判：O-f 直接改写了本册的发布判定，O-h 让四处文档的覆盖率数字错了半天（90% vs 打出的 91%，精确值只差 0.04 个百分点），O-g 说明「自动化腿变多」并不自动等于「结构问题可见」——四条既有腿全绿的同时，独立真值腿第一次跑就抓到 2 项高影响缺陷。
5. **发布判定**：按《第三轮功能测试文档》2.4 收口口径，P0 = 37/38 = 97.37%、P1 = 48/53 = 90.57%、总体 = 96/102 = 94.12%、契约缺陷 2，四项均未达门槛。**按 2.2「P0 失败即阻断发布」，本册不再出具「工程侧不阻断发布」的结论**；闭合路径只有两条——B-43/B-44 在发布前修复，或人工逐页对照真实 PDF 复核后出具书面豁免。N1–N4（B-32/B-33/B-42/B-45）继续需要人工裁定，但不属于阻断项。
