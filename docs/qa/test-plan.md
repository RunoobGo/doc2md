## 2. 测试策略与场景定义

| 场景类型 | 定义 | 设计方法 |
| --- | --- | --- |
| 正常流程（N） | 契约内的典型输入走完整链路，验证功能正确性与产物结构 | 场景法 + 等价类划分 |
| 边界条件（B） | 数值/结构边界：页数阈值、字号边界、列对齐容差、空文档、单行表 | 边界值分析 |
| 异常输入（E） | 损坏/截断/不支持/越权/冲突输入，验证错误码与退出码契约 | 错误推测法 |
| 回归场景（R） | 历史缺陷复发防护 + 既有套件/语料/黄金样本的可复现性 | 状态转换 + 回归比对 |

数据来源：`tests/corpus/`（21 份源 + 20 份目标 + manifest 哈希）；实测临时产物落 `work/tmp/e2e/`（可复核后清理）。
