## 1. 影响等级与偏差类型

| 等级 | 判定标准 | 处置口径 |
| --- | --- | --- |
| **高** | 破坏正文语义/文档结构，或把不可信内容带入下游渲染面 | 阻断发布，P0 立即修复 |
| **中** | 常见场景下结构或契约错误，调用方会误判 | 发布前修复或书面豁免 |
| **中低** | 边界路径错误，影响可感知但范围有限 | 与相关修复同批处理 |
| **低** | 可观测性、文档或结果行展示问题，不影响转换结果 | 登记后排期 |

偏差类型沿用任务口径：**功能缺失、逻辑错误、结构或格式差异、兼容性与性能问题**。安全类问题归入「结构或格式差异」，并在说明中标注安全影响。

## 5. 对照结论

1. **转换主链路可用**：22/22 语料、1208 条自动化测试、四档性能均通过，说明常规 PDF/DOCX 输入可以稳定产出可用 Markdown。
2. **「文本即 Markdown」是最大系统性缺口**：D2/D3 表明渲染层把源文本直接当 Markdown 语法解释，既是语义失真，也是下游渲染的安全边界问题。两项均判「高」，必须优先处理。
3. **结构映射的启发式需要收敛**：D7 的 14pt 提示框误判说明 N-8 仍以单一字号阈值代替版面语义；D5/D6 说明表格与分页的结构降维没有被完整暴露。
4. **出口契约不严**：D1（失败报成功）、D8（同值写算编辑）、D9（limit=0 三义）、D12（报告已删除的 zip）都属于「调用方无法从结果判断真实状态」的问题，修复成本低、收益直接。
5. **低等级项不应被忽略**：D10/D11/D13 单独看是文档/日志/错误码问题，但会直接降低排障效率；应在同一轮收尾中修掉，避免下一轮重复登记。
