# CH-501 实机自动测试体系（QA 自动化五层）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「实机自动测试」从当前**半自动、单点、只报一个综合分**的形态，升级为**一条命令跑完五层、自动生成用例文档、自动对比目标与实际、把每一分偏差归因到管线阶段、并自动产出带优先级的改进清单**的体系；同时补齐三个未生成的难度样本（D03 合并单元格 / D09 目录域 / D10 乱码文本层代理腿），把难度腿从「永远不可能真 PASS 的骨架」落成可判定断言（B-46），并修掉本轮实测发现的评测侧缺陷（`evaluate.py` 读了一个产品里不存在的 metrics 键，导致 TCOLC 从未进过任何报告）。

**Architecture:** 五个新模块 + 两处改造，全部落在**测试侧**（`tests/qa/`、`tests/corpus/`），产品包 `doc2md/` 除 `PLAN_VERSION` 常量外零改动：

- **用例生成层** `tests/qa/gen_cases.py`（改造）：难度清单 D01–D12 → 样本二进制 + `expectations.json`（构造意图，不经管线）+ **十字段用例卡**（`docs/qa/casebook.md`）；新增 `--selfcheck`（生成器自检：「我画的东西确实在文件里」）与 `--fill-results`（用实机跑批结果回填「实际结果 / 通过状态」）。
- **对账层**（已有）`tests/qa/evaluate.py` + `mdscore.py` + `srcstruct.py`：目标 ↔ 实际逐指标比对，双口径（`expected/` 只查回归漂移，`ideal/` + 源端直抽才是质量真值）。
- **归因层** `tests/qa/attribute.py`（新）：把 `1 − overall` **精确**拆到 S1 解析 / S1.5 门禁 / S2 分片缝合 / S3 结构 / S4 渲染 / LLM 六个阶段，无法归因的残差**显式计数**，恒等式 `Σ 各指标预算 = 1 − overall` 可复算。
- **缺陷层** `tests/qa/defect_scan.py`（新）：9 条产物侧结构缺陷规则（裂表 / 引导符入格 / CJK 空格吞失 / 乱码残留 / 页眉残留 / 静默降级 / 裸围栏 / 列数漂移 / 重复锚点），**每条规则自带变异自检**——正向样本必须命中、干净样本必须沉默，否则规则就是空转的（第十七轮「判定层没有牙齿」的直接对策）。
- **可追溯层** `tests/qa/trace.py`（新）：从 `docs/dev-plan.md` §2.1/§2.2 表与 `doc2md/errors.py` 抽出 FR / NFR / W / E 全集，从 `doc2md/cli.py`、`doc2md/api.py` 的 AST 抽出 CLI 子命令与 API 端点全集，反扫 `tests/**` 的引用，产出「P0 需求未覆盖」「孤儿编号」两张清单。
- **优先级层** `tests/qa/prioritize.py`（新）：影响 × 日常频率 × 本机可修性 加权 + **阻断项覆盖**（凡与发布阻断 B 号关联者无条件 P0），自动分配下一个空闲 B 号草稿（人拍板）。
- **编排层** `tests/qa/realtest.py`（新）：L0 静态 / L1 门禁 / L2 全量 / L3 资产 / L4 质量 / L5 实机探针，一条命令跑完 → `work/qa/realtest.json` + `.md`；计数一律取 `--junitxml` 的 `tests=`，**不取屏幕输出**。
- **真实样本腿** `tests/corpus/real/run_real.py`（新）：对 `work/real_samples/`（gitignored 的本机真实文档）跑 batch 画像 + 幂等 + **字段级人工抽检工作表**（按字段验收，不按字数验收）；样本不在本机时状态是 `not_run`（附原因），**绝不冒充 pass**。

**Tech Stack:** Python 3.15.0 / pytest 9.1.1（`-m gate` 红线层、`-m corpus` 信息层）/ coverage 7（`coverage run -m pytest`，**不用** `--cov`：pytest-cov 未安装）/ ruff / reportlab 4（PDF 样本）/ python-docx 1.1（DOCX 样本）/ pypdf 4（加密样本）/ pdfplumber 0.11（自检直读）/ SQLite 3.54.1。**零新增第三方依赖**：新模块只用标准库（`ast` `re` `json` `subprocess` `xml.etree` `dataclasses` `hashlib` `pathlib`）+ 已装的四个库。

**Spec:** 用户需求（2026-10-25 原话）：「制定一份全面、详细且可落地的实机自动测试方案……自动生成覆盖完整的测试文档与测试用例，自动对比目标输出与实际转化结果，量化分析偏差原因，并给出针对性的详细的优化建议与改进优先级」；参考资料 `/Volumes/fx/Object/文档转md信息收集/`（四篇：格式一致性保持、量化指标、现实困难与解决建议、`md_consistency` / `md_format` 两套实现）；项目侧锚点 `docs/dev-plan.md` §8.1（断言分层）/ §8.2（等价性纪律）/ §8.6（CI 执行点）/ §12.1（门禁与套件）/ §12.7（B-43/B-44/B-45/B-46 行）+ `docs/qa/round3/{test-plan,comparison,deviation-analysis,optimization-plan}.md`（OPT-1…OPT-17、G1–G9 根因、O-a…O-h 观察）+ `docs/review-round17-CH-500.md`（50 项对账恒等式与 O-h 三形态）。

- **不提交、不推送**：本会话从未获得提交授权。技能模板里的「Step 5: Commit」在本计划中一律替换为「记录证据（不提交）」——把命令输出、`--junitxml` 计数与文件路径写进当轮报告，`git status` 保持可见的未提交态。
- **产品字节冻结**：`PIPELINE_VERSION` 保持 **2.18.0**，`SCHEMA_VERSION` 保持 **14**，`DB_VERSION` 保持 **10**；`PLAN_VERSION` 3.34 → **3.35**（仅常量 + 文档三锚点）。本方案只新增测试侧资产；**任何改动产物字节的动作都不在本计划范围内**，若实施中发现必须改产品，先按 §8.2 做等价性证明（`git worktree` 双跑 + 逐条 sha256 + 剥 front-matter，目标 0 mismatch）并 bump `PIPELINE_VERSION`，否则停手登记。
- **零新增第三方依赖**：只用标准库与 `pyproject.toml` 已声明的 pdfplumber / python-docx / reportlab / pypdf / pytest / coverage / ruff。发现「装个包就简单了」时，登记为待办，不装。
- **双口径纪律不可违反**：`tests/corpus/expected/` = 程序产物基线，对它算分只能监控回归漂移；`tests/corpus/ideal/` + `srcstruct` 源端直抽 = 质量真值。两套数**分列不聚合**，不得把基线分当质量分上报。
- **分档不看修复成本**：`缺口` 与 `失败` 的判定只看「行为是否与既有承诺相矛盾」；修复成本只约束路径，不约束分档。**B-43（跨页表丢列并裂表）/ B-44（目录引导符成单元格 + run 间空格吞失）保持发布阻断**，本计划不得把它们降级为「缺口」或调低阈值让它们变绿。
- **绝不为了让门禁变绿而放宽阈值 / 跳过用例 / 加 `t.Skip`**；宿主相关判定改产品或测试口径，不靠 skip 掩盖。已知产品缺口只能用 `xfail(strict=True, reason="B-4x")` 钉住——缺口修好后 XPASS 会转红，逼人在同一批里删掉 xfail。
- **门禁预算**：新增 gate 项必须是**静态、毫秒级、无子进程**的（AST / 文本 / 纯函数单测）；任何会拉起真实转换的项一律标 `corpus`（信息层），不进 gate。新增 gate 项后同轮更新 `docs/dev-plan.md` §12.1 的项数（实测回填，**不预写**）与 §9.1 定档行；`tests/test_ch498_gate_budget.py` 的 `HEAVY_GATE_ITEMS` 不得外扩（新项不得签名请求 `large_pdf` / `large_single` / `large_sharded` / `large_zip_names`）。
- **难度腿标记顺序（OPT-17 既定）**：先落盘为 `corpus`，B-43 / B-44 闭合的**同一批**才切 `gate`；切换条件写死在一处常量里，切换时改那一处并在 §12.7 B-46 行回填。
- **计数证据口径**：所有项数以 `--junitxml` 的 `tests=` / `failures=` / `errors=` / `skipped=` 为准；覆盖率以 `coverage run -m pytest tests/` + `coverage report --include="doc2md/*"` 为准；四舍五入指标遵守**三写规则**（分母 + 精确值 + 打出值）。**中途快照不得当终值引用**（O-h 第三形态）。
- **文档同源同轮**：改档必须同轮更新 README「文档地图」行、dev-plan 附录 G 资产段（文件数 / 行数 / `docs/qa/` 子树计数）、§12.10 变更记录、§10.1 与 README 的 CH 编号上界；先写正文再 `wc -l`，禁止自指漂移。
- **实机 = 本机**：macOS arm64 / Python 3.15.0 / `.venv`。凡需其它主机（Win11 真机吞吐）、外部服务（llama-server、GitHub Actions 远端取证）或人工判定（真实语料标题 ground truth、契约裁定）的，**只登记为 B 类待办**，注明受限原因、验证方式与建议执行顺序，不实施。
- **数据边界**：真实用户文档只留在 `work/real_samples/`（`.gitignore` 已排除），仓库内只登记清单 / 特征计数 / ground truth（`tests/corpus/real/`）。任何新资产不得把真实文档二进制或其正文摘要带进受控文件。

### Task 1: 难度样本生成器补全（D03 / D09 / D10）+ 生成器自检

**为什么是第一步**：`tests/qa/gen_cases.py` 的 `DIFFICULTIES` 有 12 项，其中 **D03（合并单元格 ★★★★）/ D09（目录域 ★★）/ D10（CID 乱码 ★★★★★）三项 `gen: None`**，D11/D12 由既有语料覆盖。缺样本 ⇒ 用例矩阵里 S1/S2/S3 的 4 条交叉用例只有声明没有资产 ⇒ 「覆盖完整」是纸面的。而第十七轮的教训（O-g / G9）是：**真值若与产物同源，就看不见结构性损失**——所以补样本的同时必须补一条独立自检：生成器声明的意图，要用**不经管线**的读法（pdfplumber / python-docx）在源文件里复核一遍。

**Files:**
- Modify: `tests/qa/gen_cases.py`（`DIFFICULTIES` 三处 `gen` 字段、新增 5 个函数、`_GENERATORS` 注册、`main()` 加两个开关）
- Create: `tests/corpus/hard/hard_03_merged_cells.docx`、`hard_09_toc_field.docx`、`hard_10_cid_proxy.pdf`（由生成器写出，不手写）
- Regenerate: `tests/corpus/hard/expectations.json`（7 → **10** 条）
- Test: `tests/test_ch501_qa_auto.py`（本 Task 只写其中 2 项：`test_hard_expectations_have_judge_and_star`、`test_generator_registry_covers_all_open_difficulties`）

```python
def _run(*els):
    from docx.oxml import OxmlElement

    r = OxmlElement("w:r")
    for el in els:
        r.append(el)
    return r


def _fld_char(kind: str):
    from docx.oxml import OxmlElement
    from docx.oxml.ns import qn

    el = OxmlElement("w:fldChar")
    el.set(qn("w:fldCharType"), kind)
    return el


def _instr(text: str):
    from docx.oxml import OxmlElement
    from docx.oxml.ns import qn

    el = OxmlElement("w:instrText")
    el.set(qn("xml:space"), "preserve")
    el.text = text
    return el


def _text(s: str):
    from docx.oxml import OxmlElement
    from docx.oxml.ns import qn

    el = OxmlElement("w:t")
    el.set(qn("xml:space"), "preserve")
    el.text = s
    return el
```

```python
def _raw_text(path: Path) -> str:
    """源端直读（**不 import doc2md**）：自检必须独立于被测管线，否则等于自证。"""
    if path.suffix.lower() == ".pdf":
        import pdfplumber

        with pdfplumber.open(path) as pdf:
            return "\n".join((pg.extract_text() or "") for pg in pdf.pages)
    from docx import Document

    d = Document(str(path))
    parts = [p.text for p in d.paragraphs]
    for t in d.tables:
        for row in t.rows:
            parts += [c.text for c in row.cells]
    return "\n".join(parts)


def selfcheck_sources() -> list[tuple[str, bool, str]]:
    """生成器自检：expectations 的构造意图 ↔ 源端直读。

    两者不一致 = **生成器画错了**，必须先修生成器再谈产品缺陷；否则「产品没通过」
    可能只是「样本没画对」（第十七轮 O-g / G9 的同一形态：真值取自产物或与产物
    同源，就看不见损失）。自检只核生成器能控制的东西：
      1. `contains` 的每个 token 确实在源文件里（制表位按空白归一后比对）；
      2. `tables[i]` 的 ncol / nrow 与源端直抽一致（DOCX 侧）；
      3. `behavior: reject:*` 的样本不核内容（加密 / 乱码样本本就不该有可用文本）。
    """
    import re as _re

    from tests.qa import srcstruct

    specs = json.loads((HARD / "expectations.json").read_text(encoding="utf-8"))
    rows: list[tuple[str, bool, str]] = []
    for s in specs:
        src = HARD / s["source"]
        if not src.is_file():
            rows.append((s["difficulty"], False, f"{s['source']} 不存在"))
            continue
        exp = s.get("expect", {})
        if exp.get("behavior"):
            rows.append((s["difficulty"], True, "拒收样本，跳过内容自检"))
            continue
        norm = lambda t: _re.sub(r"\s+", "", t or "")   # noqa: E731
        try:
            raw = norm(_raw_text(src))
        except Exception as exc:  # noqa: BLE001
            rows.append((s["difficulty"], False, f"源端直读失败 {type(exc).__name__}: {exc}"))
            continue
        bad = [tok for tok in exp.get("contains", []) if norm(tok) not in raw]
        if bad:
            rows.append((s["difficulty"], False, f"生成器没画进去：{bad}"))
            continue
        gt = srcstruct.extract(src)
        for i, want in enumerate(exp.get("tables", [])):
            if i >= len(gt.get("tables", [])):
                bad.append(f"table[{i}] 源端直抽只有 {len(gt.get('tables', []))} 张")
                continue
            got = gt["tables"][i]
            if "ncol" in want and got.get("ncol") != want["ncol"]:
                bad.append(f"table[{i}] ncol 源端 {got.get('ncol')} != 声明 {want['ncol']}")
            if "nrow" in want and got.get("nrow") != want["nrow"]:
                bad.append(f"table[{i}] nrow 源端 {got.get('nrow')} != 声明 {want['nrow']}")
        rows.append((s["difficulty"], not bad, "; ".join(bad) or "构造意图与源端一致"))
    return rows
```

```python
_MOJIBAKE = re.compile(r"\(cid:\d+\)|\ufffd")


@dataclass
class Dev:
    stage: str
    kind: str
    metric: str
    loss: float
    severity: str          # blocking | major | minor
    evidence: str
    budgeted: bool = True

    def to_dict(self) -> dict:
        d = asdict(self)
        d["loss"] = round(self.loss, 6)
        return d


def split_tables(blocks: list) -> list[tuple[int, int]]:
    """相邻且表头相同的表格块下标对（裂表信号；defect_scan R1 复用本函数）。"""
    idx = [i for i, b in enumerate(blocks) if b.type == "table"]
    out = []
    for a, b in zip(idx, idx[1:]):
        if b != a + 1:
            continue
        ha = [re.sub(r"\s+", "", c) for c in (blocks[a].meta.get("header") or [])]
        hb = [re.sub(r"\s+", "", c) for c in (blocks[b].meta.get("header") or [])]
        if ha and ha == hb:
            out.append((a, b))
    return out


def combined_scores(rec: dict, sc: dict) -> dict[str, float]:
    """保真侧（evaluate 的 rec）+ 一致性侧（mdscore 的 sc）合成一个分数向量。"""
    s: dict[str, float] = {k: float(v) for k, v in (sc.get("scores") or {}).items()
                           if k in mdscore.CONSISTENCY_KEYS}
    h = rec.get("heading") or {}
    if h:
        # MHS 口径：标题 F1 × 层级准确率（mdscore.heading_score 的同一算法）
        s["heading"] = float(h.get("f1", 0.0)) * float(h.get("level_accuracy", 0.0))
    t = rec.get("table") or {}
    if t and t.get("teds") is not None:
        s["table"] = float(t["teds"])
    if (rec.get("structure") or {}).get("bsf") is not None:
        s["structure"] = float(rec["structure"]["bsf"])
    if (rec.get("order") or {}).get("nid") is not None:
        s["order"] = float(rec["order"]["nid"])
    return s


def quality_gap(scores: dict[str, float], profile: str) -> tuple[float, dict[str, float]]:
    """按画像权重把 1 − 综合分**精确**拆到各指标。返回 (total_gap, 逐指标预算)。"""
    weights = mdscore.PROFILES.get(profile, mdscore.PROFILES["generic"])["weights"]
    w = {k: v for k, v in weights.items() if k in scores}
    tot = sum(w.values())
    if not tot:
        return 0.0, {}
    overall = sum(scores[k] * v for k, v in w.items()) / tot
    return 1.0 - overall, {k: (v / tot) * (1.0 - scores[k]) for k, v in w.items()}


def attribute(rec: dict, sc: dict, *, md: str, blocks: list,
              ir=None, res=None) -> dict:
    """纯函数：不做转换、不读盘，因此可毫秒级单测（判定层必须有牙齿）。"""
    profile = sc.get("profile", "generic")
    scores = combined_scores(rec, sc)
    total_gap, budget = quality_gap(scores, profile)
    devs: list[Dev] = []

    def add(kind: str, metric: str, loss: float, evidence: str,
            severity: str = "major", budgeted: bool = True) -> None:
        devs.append(Dev(stage=KIND_STAGE[kind], kind=kind, metric=metric,
                        loss=max(0.0, loss), severity=severity,
                        evidence=evidence, budgeted=budgeted))

    sharded = bool(getattr(ir, "sharded", False))
    warnings = list(((res.meta or {}).get("warnings", []) if res else []) or [])
    splits = split_tables(blocks)

    # --- heading：按计数拆三段，F1 是调和均值，拆不干净的残差进 unattributed ---
    hb = budget.get("heading", 0.0)
    h = rec.get("heading") or {}
    if hb > 0 and h:
        nref, npred = max(1, int(h.get("ref", 0))), max(1, int(h.get("pred", 0)))
        miss = int(h.get("fn", 0)) / nref
        false = int(h.get("fp", 0)) / npred
        level = (int(h.get("matched_text_only", 0)) - int(h.get("matched", 0))) / nref
        parts = {"heading_missed": miss, "heading_false": false, "heading_level": level}
        ssum = sum(parts.values())
        scale = (hb / ssum) if ssum > 0 else 0.0
        for kind, ratio in parts.items():
            if ratio > 0:
                add(kind, "heading", ratio * scale,
                    f"{h.get('fn', 0)} 漏 / {h.get('fp', 0)} 误 / "
                    f"层级错 {int(h.get('matched_text_only', 0)) - int(h.get('matched', 0))}")
        if ssum <= 0:
            # 计数全为 0 但 F1 < 1（例如两侧皆空却给了缺口）：拆不动，进伪阶段
            devs.append(Dev(UNATTRIBUTED, "heading_residual", "heading", hb,
                            "minor", "标题缺口无法按计数拆分（调和均值残差）",
                            budgeted=True))

    # --- table：漏检 / 裂表 / 形状 / 内容 ---
    tb = budget.get("table", 0.0)
    t = rec.get("table") or {}
    if tb > 0 and t:
        nref = max(1, int(t.get("n_ref", 0)))
        missed = int(t.get("missed", 0)) / nref
        shape = t.get("shape_ok")
        shape_gap = (1.0 - float(shape)) / nref if shape is not None else 0.0
        kind = "table_split" if splits else "table_missed"
        if missed > 0:
            ev = f"漏检 {t.get('missed')} 张"
            if splits:
                ev += f"；检出裂表 {len(splits)} 处（下标 {splits}，相邻同表头）"
            add(kind, "table", missed * tb, ev, "blocking" if splits else "major")
        if shape_gap > 0:
            add("table_shape", "table", shape_gap * tb,
                f"列数一致率 {shape}（源端 {t.get('n_ref')} 张）")
        rest = tb * (1.0 - missed - shape_gap)
        if rest > 1e-9:
            add("table_content", "table", rest,
                f"found-only TEDS {t.get('found_only')}：表找到了但单元格内容/结构有损")

    # --- structure / order：分片场景优先归缝合，否则归结构 ---
    for metric, key in (("structure", "bsf"), ("order", "nid")):
        b = budget.get(metric, 0.0)
        if b <= 0:
            continue
        val = (rec.get(metric) or {}).get(key)
        kind = "structure_order" if (sharded or splits) else "structure_blocks"
        add(kind, metric, b, f"{metric}.{key}={val}"
                             + ("（分片/裂表场景）" if kind == "structure_order" else ""))

    # --- 一致性侧：逐项直归 S4，honest 归 S1（W1045 的检出点）---
    lb = budget.get("lint_contract", 0.0)
    if lb > 0:
        by_rule = ((sc.get("detail") or {}).get("lint") or {}).get("by_class", {})
        add("lint_contract", "lint_contract", lb,
            f"契约类违规 {json.dumps(by_rule.get('contract', {}), ensure_ascii=False)}")
    ab = budget.get("asset", 0.0)
    if ab > 0:
        det = (sc.get("detail") or {}).get("asset") or {}
        add("asset_broken", "asset", ab,
            f"断链 {det.get('total', 0) - det.get('resolved', 0)} / {det.get('total', 0)}")
    rb = budget.get("render", 0.0)
    if rb > 0:
        add("render_redline", "render", rb,
            f"红线命中 {json.dumps((sc.get('detail') or {}).get('render', {}).get('hits', {}), ensure_ascii=False)}",
            "blocking")
    hob = budget.get("honest", 0.0)
    if hob > 0:
        add("silent_degrade", "honest", hob,
            f"产物有降级形态但无 W104x 告警：{(sc.get('detail') or {}).get('honest', {})}",
            "blocking")
    ib = budget.get("idempotent", 0.0)
    if ib > 0:
        if sharded:
            add("idempotent_break", "idempotent", ib,
                f"分片场景 N 次输出不一致（{(sc.get('detail') or {}).get('idempotent', {})}）",
                "blocking")
        else:
            devs.append(Dev(UNATTRIBUTED, "idempotent_unattributed", "idempotent",
                            ib, "blocking", "非分片场景的不一致：阶段不可判定，"
                            "需 --repeats 3 复现后人工定位", budgeted=True))

    # --- 契约违规（不占预算，loss=0）---
    body = mdscore.strip_front_matter(md or "")[1]
    if _MOJIBAKE.search(body):
        add("cid_mojibake", "-", 0.0, f"乱码残留 {_MOJIBAKE.findall(body)[:3]}",
            "blocking", budgeted=False)
    furn = [ln for ln in body.split("\n") if _FURNITURE.match(ln)]
    if furn:
        add("furniture_residue", "-", 0.0, f"页眉/页码残留 {len(furn)} 行：{furn[:3]}",
            "major", budgeted=False)
    for w in warnings:
        code = w.split(":")[0] if isinstance(w, str) else str(w)
        if code in ("W1043", "W1044"):
            add("shard_warning", "-", 0.0, f"告警 {w}", "major", budgeted=False)
    if res is not None:
        rej = list(getattr(res, "rejected_ops", []) or [])
        if rej:
            add("llm_ops_rejected", "-", 0.0, f"LLM 算子被拒 {len(rej)} 条",
                "minor", budgeted=False)

    attributed = sum(d.loss for d in devs if d.budgeted and d.stage in STAGES)
    unattr = [d for d in devs if d.stage == UNATTRIBUTED and d.budgeted]
    unattributed_loss = sum(d.loss for d in unattr)
    unattributed_n = len(unattr)
    by_stage = {}
    for st in STAGES:
        ds = [d for d in devs if d.stage == st]
        by_stage[st] = {"count": len(ds),
                        "budgeted": sum(1 for d in ds if d.budgeted),
                        "loss": round(sum(d.loss for d in ds if d.budgeted), 6),
                        "kinds": sorted({d.kind for d in ds}),
                        "severities": sorted({d.severity for d in ds})}
    residual = total_gap - attributed - unattributed_loss
    return {
        "profile": profile,
        "scores": {k: round(v, 4) for k, v in scores.items()},
        "budget": {k: round(v, 6) for k, v in budget.items()},
        "total_gap": round(total_gap, 6),
        "deviations": [d.to_dict() for d in devs],
        "by_stage": by_stage,
        "unattributed": {"count": unattributed_n,
                         "loss": round(unattributed_loss, 6)},
        "identity": {"total_gap": round(total_gap, 6),
                     "attributed": round(attributed, 6),
                     "unattributed_loss": round(unattributed_loss, 6),
                     "residual": round(residual, 9),
                     "ok": abs(residual) < 1e-9},
        "signals": {"sharded": sharded, "split_tables": splits,
                    "warnings": warnings},
    }


def attribute_one(source: Path, *, out_dir: Path, profile: str = "generic",
                  repeats: int = 1, sink: dict | None = None) -> dict:
    """单样本：一次真机转换 → 目标侧装配 → 归因。

    `sink` 与 `run_hard.check_spec` 同形：给一个 dict，就把产物 Markdown 写进
    `sink["md"]`（Task 9 的真实样本腿要拿它算人工真值召回，不该去猜产物落盘路径）。
    """
    out: dict = {"source": source.name, "kind": source.suffix.lstrip(".").lower()}
    try:
        res = convert(source, out_dir=out_dir, force=True)
    except Doc2mdError as exc:
        out["status"] = "rejected"
        out["error_code"] = exc.code
        out["deviations"] = [Dev(KIND_STAGE["gate_verdict"], "gate_verdict", "-",
                                 0.0, "major", f"reject:{exc.code}",
                                 budgeted=False).to_dict()]
        out["by_stage"] = {st: {"count": 0, "budgeted": 0, "loss": 0.0,
                                "kinds": [], "severities": []} for st in STAGES}
        out["identity"] = {"total_gap": 0.0, "attributed": 0.0,
                           "unattributed_loss": 0.0, "residual": 0.0, "ok": True}
        return out
    except Exception as exc:  # noqa: BLE001
        out["status"] = "error"
        out["error"] = f"{type(exc).__name__}: {exc}"
        return out

    md = res.markdown
    if sink is not None:
        sink["md"] = md
    blocks = mdscore.parse_blocks(md)
    gt = src_extract.extract(source)
    ideal = evaluate.load_ideal(source.name)
    ref_headings = ((ideal or {}).get("headings") or gt.get("headings") or []) \
        if (ideal or gt) else []
    rec = {
        "status": "ok",
        "heading": evaluate.heading_f1(blocks, ref_headings),
        "table": evaluate.table_f1(blocks, gt.get("tables", [])),
        "structure": {"bsf": mdscore.structure_f1(
            evaluate.skeleton(blocks), evaluate.build_ref_blocks(source))[0]},
        "order": {"nid": mdscore.reading_order_nid(
            evaluate.skeleton(blocks), evaluate.build_ref_blocks(source))},
        "counts": {"list_items": evaluate.count_delta(
            evaluate.product_counts(blocks)["list_items"], gt.get("list_items"))},
    }
    mds = [md]
    for _ in range(max(0, repeats - 1)):
        mds.append(convert(source, out_dir=out_dir, force=True).markdown)
    warnings = list((res.meta or {}).get("warnings", []) or [])
    sc = mdscore.score(md, ref=None, ref_kind="none", profile=profile,
                       repeats=mds if len(mds) > 1 else None, warnings=warnings,
                       tcolc=(res.metrics or {}).get("table_col"))
    out["status"] = "ok"
    out["tcolc"] = (res.metrics or {}).get("table_col")
    out.update(attribute(rec, sc, md=md, blocks=blocks, ir=res.ir, res=res))
    out["record"] = rec
    return out
```

### Task 4: 缺陷扫描器 `defect_scan.py` —— 9 条规则，每条自带变异自检

**为什么**：第十七轮最刺眼的观察是「**判定层没有牙齿**」——`test_hard_corpus.py` 的断言写成了「有缺口就 xfail、没缺口就 skip」，于是它无论产品好坏都绿。规则型判定器如果只做「跑一遍看看有没有命中」，同样会退化成空转：一条永远不命中的规则和一条不存在的规则在报告里长得一样。所以本 Task 的每条规则都必须配一对**变异样本**（正向必须命中、干净必须沉默），并把「规则非空转」本身做成 gate 红线。

```python
@pytest.mark.gate
def test_defect_scan_rules_are_not_vacuous():
    """每条规则都必须被自己的变异样本触发——永远不命中的规则等于不存在。"""
    ds = _load("defect_scan")
    assert set(ds.RULE_SELFTESTS) == set(ds.RULES), (
        f"自检样本与规则集不同源：缺 {sorted(set(ds.RULES) - set(ds.RULE_SELFTESTS))}")
    for name, (pos, _neg, pctx, _nctx) in ds.RULE_SELFTESTS.items():
```

```python
# -*- coding: utf-8 -*-
"""trace.py —— 需求 ↔ 测试可追溯矩阵。

回答一个此前只能靠人翻的问题：**28 条 FR、11 条 NFR、14 个 E 码、4 个 W 码、
11 个 CLI 子命令、22 个 API 端点，哪些真的有测试引用？**

三条纪律：
  1. **以代码为准**：W 码取 `doc2md.errors` 的 `WARN_*` 常量值、E 码取 `CODE_INDEX`
     的键，不从文档表格抄——文档抄出来的清单永远比代码晚一轮（第十七轮 8 处文档
     改正就是这个形态）。文档侧只用来抽 FR/NFR 的**名称与优先级**。
  2. **锚点先解析再比值**：解析不到就报「锚点失效」，不许静默恒真
     （`test_ch477_version_sync` 的既定纪律）。
  3. **「覆盖」只表示可追溯，不表示测得对**：本模块不判定测试质量，那是
     `defect_scan` 的变异自检与 `test_hard_gate` 的断言形态负责的事。

用法：
    .venv/bin/python tests/qa/trace.py --md work/qa/trace.md
"""
from __future__ import annotations

import argparse
import ast
import json
import re
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
REPO = HERE.parents[1]
sys.path.insert(0, str(REPO))

DEV_PLAN = REPO / "docs" / "dev-plan.md"
TESTS = REPO / "tests"

RE_ID = re.compile(r"\b(FR-\d{3}|NFR-\d{1,2}|W10\d{2}|E\d{4})\b")
_VERBS = {"get": "GET", "post": "POST", "put": "PUT", "patch": "PATCH",
          "delete": "DELETE"}


def declared_requirements(dev_plan: Path = DEV_PLAN) -> dict[str, dict]:
    """从 §2.1 / §2.2 的表格行抽 FR / NFR（含名称与优先级）。"""
    out: dict[str, dict] = {}
    for ln in dev_plan.read_text(encoding="utf-8").split("\n"):
        m = re.match(r"^\|\s*(FR-\d{3})\s*\|\s*([^|]*?)\s*\|\s*(P\d)\s*\|", ln)
        if m:
            out[m.group(1)] = {"name": m.group(2), "priority": m.group(3),
                               "section": "2.1"}
            continue
        m = re.match(r"^\|\s*(NFR-\d{1,2})\s*\|\s*([^|]*?)\s*\|", ln)
        if m:
            out[m.group(1)] = {"name": m.group(2), "priority": "",
                               "section": "2.2"}
    return out


def declared_codes() -> dict[str, list[str]]:
    """W / E 码**以代码为准**（见模块 docstring 纪律 1）。"""
    import doc2md.errors as errors

    ws = sorted({v for k, v in vars(errors).items()
                 if k.startswith("WARN_") and isinstance(v, str)})
    return {"W": ws, "E": sorted(errors.CODE_INDEX)}


def cli_subcommands() -> list[str]:
    tree = ast.parse((REPO / "doc2md" / "cli.py").read_text(encoding="utf-8"))
    out = []
    for node in ast.walk(tree):
        if (isinstance(node, ast.Call)
                and getattr(node.func, "attr", "") == "add_parser"
                and node.args and isinstance(node.args[0], ast.Constant)
                and isinstance(node.args[0].value, str)):
            out.append(node.args[0].value)
    return sorted(set(out))


def api_endpoints() -> list[str]:
    tree = ast.parse((REPO / "doc2md" / "api.py").read_text(encoding="utf-8"))
    out = []
    for node in ast.walk(tree):
        if not isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            continue
        for dec in node.decorator_list:
            if not (isinstance(dec, ast.Call) and isinstance(dec.func, ast.Attribute)):
                continue
            verb = _VERBS.get(dec.func.attr)
            if (verb and getattr(dec.func.value, "id", "") == "app"
                    and dec.args and isinstance(dec.args[0], ast.Constant)):
                out.append(f"{verb} {dec.args[0].value}")
    return sorted(set(out))


def scan_references(tests_dir: Path = TESTS) -> dict[str, list[str]]:
    """编号 → 引用它的测试（`文件::函数`）。按函数体切分，避免整文件粗匹配。

    名字刻意**不叫 `test_*`**：本文件长在 `tests/` 树下，而 `pytest tests/qa/trace.py`
    这种直接指定文件的调用会无视 `python_files = test_*.py` 去收集 `test_*` 函数——
    一个恒真的「测试」就这样混进证据链。
    """
    out: dict[str, list[str]] = {}
    for path in sorted(tests_dir.rglob("test_*.py")):
        src = path.read_text(encoding="utf-8")
        try:
            tree = ast.parse(src, filename=str(path))
        except SyntaxError:
            continue
        rel = path.relative_to(REPO).as_posix()
        for fn in tree.body:
            if not isinstance(fn, (ast.FunctionDef, ast.AsyncFunctionDef)):
                continue
            if not fn.name.startswith("test_"):
                continue
            seg = ast.get_source_segment(src, fn) or ""
            for ident in set(RE_ID.findall(seg)):
                out.setdefault(ident, []).append(f"{rel}::{fn.name}")
        # 模块级引用（pytestmark / 常量表 / 参数化列表）单独归到 ::<module>
        head = "\n".join(ln for ln in src.split("\n")
                         if not ln.startswith((" ", "\t")))
        for ident in set(RE_ID.findall(head)):
            out.setdefault(ident, []).append(f"{rel}::<module>")
    return out


def trace(*, dev_plan: Path = DEV_PLAN) -> dict:
    reqs = declared_requirements(dev_plan)
    codes = declared_codes()
    cli = cli_subcommands()
    api = api_endpoints()
    refs = scan_references()

    declared = set(reqs) | set(codes["W"]) | set(codes["E"])
    orphans = sorted(k for k in refs if k not in declared)
    uncovered = {
        "FR_P0": sorted(k for k, v in reqs.items()
                        if k.startswith("FR-") and v["priority"] == "P0" and k not in refs),
        "FR_other": sorted(k for k, v in reqs.items()
                           if k.startswith("FR-") and v["priority"] != "P0" and k not in refs),
        "NFR": sorted(k for k in reqs if k.startswith("NFR-") and k not in refs),
        "W": sorted(k for k in codes["W"] if k not in refs),
        "E": sorted(k for k in codes["E"] if k not in refs),
    }
    return {
        "requirements": reqs, "codes": codes, "cli": cli, "api": api,
        "refs": {k: sorted(set(v)) for k, v in refs.items()},
        "uncovered": uncovered, "orphans": orphans,
        "coverage": {
            "FR": round(sum(1 for k in reqs if k.startswith("FR-") and k in refs)
                        / max(1, sum(1 for k in reqs if k.startswith("FR-"))), 4),
            "NFR": round(sum(1 for k in reqs if k.startswith("NFR-") and k in refs)
                         / max(1, sum(1 for k in reqs if k.startswith("NFR-"))), 4),
            "W": round(sum(1 for k in codes["W"] if k in refs) / max(1, len(codes["W"])), 4),
            "E": round(sum(1 for k in codes["E"] if k in refs) / max(1, len(codes["E"])), 4),
        },
    }
```

### Task 6: 优先级层 `tests/qa/prioritize.py` —— 影响 × 频率 → 分档，成本只排期

**为什么**：第三轮 QA 的优化方案（`docs/qa/round3/optimization-plan.md`）是**人手排**的优先级，OPT-1…OPT-N 的顺序靠判断，没有可复算的依据；第十七轮又确立了一条硬纪律——**分档不看修复成本**（「缺口 vs 失败」只由「行为是否违背既有承诺」决定，成本只约束路径）。这两件事必须同时成立，所以本层的口径是：

- **分档（P0/P1/P2）只由 `影响 × 频率` 决定**，外加一条无条件覆盖：`blocking` 项恒 P0；
- **可修复性（fixability）不进分档，只进同档内的排期序**，并同时决定处置路径（本机实施 / 重烤 / 人工 / 外部）；
- 需人工或外部环境的项**自动拟一个 B 草稿号**，落盘由人工在 Task 10 确认——号是草稿，不是既成事实。

第三个恒等式（前两个：CH-500 的 50 项分解、Task 3 的归因预算分解）：

```
条目数 == 分档合计 == 来源合计 == 唯一 (来源, 键) 数
```

即「每一条输入候选都出现且只出现一次，没有凭空多出来的优先级项」。

def test_fixability_does_not_downgrade_grade():
    """第十七轮纪律：分档不看修复成本——成本只改同档内的顺序与处置路径。"""
    pr = _load("prioritize")

                        "loss", False, 0.5, 3, "ev", "")
    easy = pr.make_item("attribution", "k", "t", "-", 1.0, 1.0, pr.FIX_LOCAL,
                        "loss", False, 0.5, 3, "ev", "")
    assert hard.score == easy.score and hard.priority == easy.priority == "P0"
    assert hard.disposition == "external" and easy.disposition == "fix_local"
    key = lambda it: (it.priority, -it.score, -it.fixability)   # noqa: E731
    assert sorted([hard, easy], key=key)[0] is easy, "同档内应先做本机可自证的"
    order = {"P0": 0, "P1": 1, "P2": 2}
    assert order[pr.bucket(0.9, False)] <= order[pr.bucket(0.5, False)] \
        <= order[pr.bucket(0.1, False)]
    assert pr.bucket(0.5, False) == "P1" and pr.bucket(0.1, False) == "P2"
    assert pr.bucket(0.0, True) == "P0", "阻断项无条件 P0"

```python
"""prioritize.py —— 优先级引擎：把三层证据排成一张可复算的施工单。

两条口径必须同时成立，它们互相拉扯，所以写死在这里：

  * **分档只看影响面与重复率**（`W = impact 0.6 + frequency 0.4`），外加一条无条件

def release_blocking(dev_plan: str) -> set[str]:

class Item:

    key: str             # 偏差类型 / 规则名 / trace 分组 / eval 分组
    title: str
    stage: str           # 管线阶段，非管线项为 "-"
    impact: float
    frequency: float

    score: float
    priority: str        # P0 | P1 | P2

    loss: float

    evidence: str
    b_linked: str = ""
    b_draft: str = ""
    disposition: str = ""

        return asdict(self)


def score_item(impact: float, frequency: float) -> float:
    return round(W["impact"] * impact + W["frequency"] * frequency, 6)


def bucket(score: float, blocking: bool) -> str:
    """分档。blocking 无条件 P0；否则按分数落档。**fixability 不参与。**"""
    if blocking:
        return "P0"
    if score >= P0_FLOOR:
        return "P0"
    return "P1" if score >= P1_FLOOR else "P2"


def make_item(origin: str, key: str, title: str, stage: str, impact: float,
              frequency: float, fixability: float, basis: str, blocking: bool,
              loss: float, n_sources: int, evidence: str, b_linked: str,
              **extra) -> Item:
    score = score_item(impact, frequency)
    return Item(origin=origin, key=key, title=title, stage=stage,
                impact=round(min(1.0, max(0.0, impact)), 4),
                frequency=round(min(1.0, max(0.0, frequency)), 4),
                fixability=fixability, score=score,
                priority=bucket(score, blocking), blocking=blocking, basis=basis,
                loss=round(loss, 6), n_sources=n_sources,
                evidence=(evidence or "")[:200], b_linked=b_linked,
                disposition=DISPOSITION[fixability], extra=extra)
```

```python
def collect(*, attribution: dict | None = None, defects: dict | None = None,
            trace: dict | None = None, eval_summary: dict | None = None,
            dev_plan: str | None = None) -> list[Item]:
    dp = DEV_PLAN.read_text(encoding="utf-8") if dev_plan is None else dev_plan
    block_b = release_blocking(dp)
    items: list[Item] = []

    # ① 归因层：预算内偏差的 impact = 该类型 loss 占全语料 total_gap 之比；
    #    契约类偏差 loss=0，impact 改按严重度映射（basis 显式打出用的是哪一种）
    if attribution:
        recs = [r for r in attribution.get("records", []) if r.get("status") == "ok"]
        n = max(1, len(recs))
        gap = sum(float(r.get("total_gap", 0.0)) for r in recs)
        agg: dict[str, dict] = {}
        for r in recs:
            for d in r.get("deviations", []):
                a = agg.setdefault(d["kind"], {"loss": 0.0, "n": 0, "sev": "minor",
                                              "stage": d.get("stage", "-"), "ev": ""})
                a["loss"] += float(d.get("loss", 0.0))
                a["n"] += 1
                a["sev"] = _worse(a["sev"], d.get("severity", "minor"))
                a["ev"] = a["ev"] or d.get("evidence", "")
        for kind, a in sorted(agg.items()):
            if a["loss"] > 0 and gap > 0:
                impact, basis = min(1.0, a["loss"] / gap), "loss"
            else:
                impact, basis = SEVERITY_IMPACT[a["sev"]], "severity"
            b = LINK_B.get(kind, "")
            items.append(make_item(
                "attribution", kind, f"偏差类型 {kind}（{a['stage']}）", a["stage"],
                impact, a["n"] / n, FIXABILITY[kind], basis,
                a["sev"] == "blocking" or b in block_b, a["loss"], a["n"],
                a["ev"], b))

    # ② 缺陷层：impact 按严重度，frequency = 命中样本数 / ok 样本数
    if defects:
        recs = [r for r in defects.get("records", []) if r.get("status") == "ok"]
        n = max(1, len(recs))
        agg = {}
        for r in recs:
            for f in r.get("findings", []):
                a = agg.setdefault(f["rule"], {"sev": "minor", "ev": "", "src": set()})
                a["src"].add(r.get("source", "?"))
                a["sev"] = _worse(a["sev"], f.get("severity", "minor"))
                a["ev"] = a["ev"] or f.get("evidence", "")
        for rule, a in sorted(agg.items()):
            b = LINK_B.get(rule, "")
            items.append(make_item(
                "defect", rule, f"规则命中 {rule}（{RULE_STAGE[rule]}）",
                RULE_STAGE[rule], SEVERITY_IMPACT[a["sev"]], len(a["src"]) / n,
                FIXABILITY[rule], "severity",
                a["sev"] == "blocking" or b in block_b, 0.0, len(a["src"]), a["ev"], b))

    # ③ 可追溯层：结构性缺口，每轮恒定存在 ⇒ frequency = 1.0（basis=structural）
    if trace:
        unc = trace.get("uncovered", {})
        for grp in ("FR_P0", "FR_other", "NFR", "E", "W"):
            ids = sorted(unc.get(grp, []))
            if ids:
                items.append(make_item("trace", grp, TRACE_TITLE[grp], "-",
                                       TRACE_IMPACT[grp], 1.0, FIX_LOCAL,
                                       "structural", grp == "FR_P0", 0.0, len(ids),
                                       ", ".join(ids[:12]), ""))
        orph = sorted(trace.get("orphans", []))
        if orph:
            items.append(make_item("trace", "orphans", "测试引用了不存在的编号", "-",
                                   0.2, 1.0, FIX_LOCAL, "structural", False, 0.0,
                                   len(orph), ", ".join(orph[:12]), ""))

    # ④ 全量对账层：产品基线腿（expected/）红 = 已交付基线漂移，恒 blocking
    if eval_summary:
        n = max(1, int(eval_summary.get("n_ok", 0)))
        gf = eval_summary.get("gate_failures", [])
        if gf:
            items.append(make_item("eval", "gate_failures",
                                   "产品基线红线失败（expected/ 漂移）", "-", 1.0,
                                   len(gf) / n, FIX_LOCAL, "severity", True, 0.0,
                                   len(gf), ", ".join(g["source"] for g in gf[:12]), ""))
        if eval_summary.get("n_error"):
            items.append(make_item("eval", "errors", "转换异常（status=error）", "-",
                                   1.0, int(eval_summary["n_error"]) / n, FIX_LOCAL,
                                   "severity", True, 0.0, int(eval_summary["n_error"]),
                                   "详见 eval.json 的 records[].error", ""))
    return items
```

`prioritize()` 做三件事：排序（分档 → 分数 → 可修复性 → 来源 → 键）、拟 B 草稿号、算恒等式。

```python
def prioritize(*, attribution=None, defects=None, trace=None, eval_summary=None,
               dev_plan=None) -> dict:
    dp = DEV_PLAN.read_text(encoding="utf-8") if dev_plan is None else dev_plan
    items = collect(attribution=attribution, defects=defects, trace=trace,
                    eval_summary=eval_summary, dev_plan=dp)
    items.sort(key=lambda it: (it.priority, -it.score, -it.fixability,
                               it.origin, it.key))
    # 拟新号：只给「需人工裁定 / 需外部环境」且尚未登记的项。
    # rebake **不占号**——重烤是本机可执行的实施动作（人工复核是其验收步骤），
    # 进实施队列；真值本身只能人工对照的（如 B-43）本来就落在 human。
    nxt = next_free_b(dp)
    for it in items:
        if it.b_linked or it.disposition not in ("human", "external"):
            continue
        it.b_draft = f"B-{nxt}"
        nxt += 1
    counts = {p: sum(1 for it in items if it.priority == p) for p in ("P0", "P1", "P2")}
    origins: dict[str, int] = {}
    for it in items:
        origins[it.origin] = origins.get(it.origin, 0) + 1
    uniq = {(it.origin, it.key) for it in items}
    return {
        "generated_at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "weights": W, "floors": {"P0": P0_FLOOR, "P1": P1_FLOOR},
        "items": [it.to_dict() for it in items],
        "counts": counts, "origins": origins, "b_next": nxt,
        "blocking": sorted({(it.b_linked or it.b_draft) for it in items
                            if it.blocking and (it.b_linked or it.b_draft)}),
        "identity": {"n_items": len(items),
                     "by_priority": sum(counts.values()),
                     "by_origin": sum(origins.values()),
                     "unique_keys": len(uniq),
                     "ok": len(items) == sum(counts.values())
                           == sum(origins.values()) == len(uniq)},
    }
```

```python
    assert rt.layer_status([rt.Check("a", rt.PASS), rt.Check("b", rt.FAIL)]) == rt.FAIL

    blk = rt.Layer("L1_gate", True, [rt.Check("x", rt.PASS)])
```

```python
def junit_counts(path: Path) -> dict | None:
    """从 junitxml 读计数。**缺失/解析失败返回 None**，绝不返回全 0。

    输入是本机 pytest 自己写的 junitxml（可信来源），不接受外部 XML。
    `xfail` 单独数：pytest 把 `<skipped type="pytest.xfail">` 折进 `skipped` 属性
    （本机实测），四元组会把「已知缺口」和「真跳过」混成一个数——报告必须拆开。
    """
    if not path.exists():
        return None
    try:
        root = ET.parse(path).getroot()
    except ET.ParseError:
        return None
    suites = [root] if root.tag == "testsuite" else list(root.iter("testsuite"))
    out = {"tests": 0, "failures": 0, "errors": 0, "skipped": 0}
    for s in suites:
        for k in out:
            out[k] += int(s.get(k) or 0)
    out["xfail"] = sum(1 for sk in root.iter("skipped")
                       if sk.get("type") == "pytest.xfail")
    out["passed"] = out["tests"] - out["failures"] - out["errors"] - out["skipped"]
    return out


def _run(cmd: list[str], timeout: int) -> tuple[int, str, str, float]:
    t0 = time.monotonic()
    p = subprocess.run(cmd, cwd=REPO, capture_output=True, text=True, timeout=timeout)
    return p.returncode, p.stdout, p.stderr, round(time.monotonic() - t0, 2)


def _tail(text: str, n: int = 1200) -> str:
    return (text or "")[-n:]
```

```python
def run(*, only: tuple[str, ...] = (), out_dir: Path, coverage: bool = False,
        profile: str = "generic") -> dict:
    out_dir.mkdir(parents=True, exist_ok=True)
    want = set(only) if only else set(LAYERS)
    layers: list[Layer] = []
    counts: dict[str, dict | None] = {}
    if "L0_static" in want:
        layers.append(l0_static())
    if "L1_gate" in want:
        ly, c = l1_gate(out_dir); layers.append(ly); counts["L1_gate"] = c
    if "L2_full" in want:
        ly, c = l2_full(out_dir, coverage=coverage); layers.append(ly); counts["L2_full"] = c
    if "L3_assets" in want:
        layers.append(l3_assets())
    if "L4_install" in want:
        layers.append(l4_install(out_dir))
    if "L5_quality" in want:
        layers.append(l5_quality(out_dir, profile=profile))
    skipped = [n for n in LAYERS if n not in want]
    return {
        "generated_at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "host": {"platform": sys.platform, "python": sys.version.split()[0],
                 "executable": sys.executable, "pipeline": PIPELINE_VERSION},
        "selected": sorted(want), "skipped": skipped,
        "overall": overall(layers),
        "layers": [ly.to_dict() for ly in layers],
        "counts": counts,
        "not_run": [{"layer": ly.name, "check": c.name, "detail": c.detail}
                    for ly in layers for c in ly.checks if c.status == NOT_RUN],
    }
```

`report_md(payload)`：① 首屏三行——`overall`、宿主四元组（platform / python / executable / pipeline）、**`not_run` 清单**（空则写「无」）；② 每层一张表 `| 检查 | 状态 | 详情 | 秒 |`；③ L1/L2 的 junit 四元组单独成行（三写规则：`tests=` 原值 + `passed=` + `failures/errors/skipped`）；④ 末行
`REALTEST overall=<x> L1=<tests>/<fail>/<err>/<skip> L2=<…> NOTRUN=<k>`。
`main()` 退出码：`overall == FAIL` → 1，否则 0（`NOT_RUN` 退 0，但报告首屏显形——**编排器不因为「有腿没跑」而假装失败，也不因为「有腿没跑」而假装通过**）。

```python
def expand_only(raw: str) -> tuple[str, ...]:
    """`"L0,L1"` → `("L0_static", "L1_gate")`；空串 = 全跑。

    认不出的 token 直接退出：静默选空会让六层全 `skipped`、整体 `not_run`，
    报告形态与「忘了跑」一模一样。
    """
    if not raw.strip():
        return ()
    out: list[str] = []
    for tok in (t.strip().upper() for t in raw.split(",")):
        if not tok:
            continue
        hits = [n for n in LAYERS if n == tok or n.split("_")[0] == tok]
        if not hits:
            raise SystemExit(
                f"--only 的 '{tok}' 不匹配任何层（可选前缀 L0…L5 或层全名："
                f"{', '.join(LAYERS)}）")
        out += hits
    return tuple(dict.fromkeys(out))

    ap.add_argument("--json", default=str(REPO / "work" / "qa" / "realtest.json"))
    ap.add_argument("--md", default=str(REPO / "work" / "qa" / "realtest.md"))
    a = ap.parse_args(argv)

                       (a.md, report_md(payload))):
```

### Task 8: 用例卡十字段 + 实测回填 `gen_cases.py --fill-results`

**为什么**：用户要的测试文档是**每条用例十个字段**（编号 / 所属模块 / 测试目标 / 输入与前置条件 / 执行步骤 / 期望结果 / 实际结果 / 通过状态 / 优先级 / 覆盖指标）。现在的 `docs/qa/casebook.md`（87 行）只到「TC-005」这个编号为止——**没有期望、没有实际、没有通过状态**，它是一张索引，不是用例集。第三轮 QA 的实测结果散在 `docs/qa/round3/comparison.md` 的散文里，与用例编号不对齐，所以「TC-005 现在到底过不过」这个问题需要人去翻两份文档拼。

本 Task 把十字段做成**生成器产物**，且「实际结果 / 通过状态 / 优先级」三个字段**只能从本轮 `work/qa/*.json` 回填**，回填时必须带上产物的 `generated_at`。三条纪律：

```python
def fill_results(results_dir: Path) -> dict:
    """读 work/qa/*.json。**缺文件就记 missing，不猜、不沿用旧值。**"""
    ev: dict = {"dir": str(results_dir), "missing": [], "generated_at": {}, "data": {}}
    for name in ("realtest", "attribution", "defects", "priorities", "eval"):
        p = results_dir / f"{name}.json"
        if not p.is_file():
            ev["missing"].append(name)
            continue
        blob = json.loads(p.read_text(encoding="utf-8"))
        ev["data"][name] = blob
        ev["generated_at"][name] = blob.get("generated_at", "?")
    return ev


def _source_record(ev: dict, layer: str, source: str) -> dict | None:
    for r in (ev["data"].get(layer, {}) or {}).get("records", []):
        if r.get("source") == source:
            return r
    return None


def card_status(difficulty: str, ev: dict) -> tuple[str, str]:
    """(通过状态, 实际结果)。四值封闭：通过 / 失败 / 缺口·B-xx / 未执行。"""
    carrier = CARRIER.get(difficulty, "")
    if not carrier:
        return "未执行", "本机无载体样本（需真机文档，见 §12.7 登记）"
    if not ev["data"]:
        return "未执行", f"本轮未提供证据（缺 {', '.join(ev['missing']) or '全部'}）"
    src = Path(carrier).name
    att = _source_record(ev, "attribution", src)
    dsc = _source_record(ev, "defects", src)
    rt = ev["data"].get("realtest", {})
    ts = {c["name"]: c for ly in rt.get("layers", []) for c in ly.get("checks", [])}
    stamp = ev["generated_at"].get("attribution", "?")
    if att is None and dsc is None:
        why = f"证据里没有 {src} 的记录"
        if difficulty in ("D01", "D02", "D03", "D04", "D05", "D06", "D07", "D08",
                          "D09", "D10"):
            why += "（难度腿不在 attribution 的 22 篇语料清单里，需 run_hard 输出）"
        return "未执行", f"{why}；run_hard 状态见 realtest.json 的 L5.hard_leg"
    blocking = [d for d in (att or {}).get("deviations", [])
                if d.get("severity") == "blocking"]
    hits = [f for f in (dsc or {}).get("findings", [])
            if f.get("severity") in ("blocking", "major")]
    b = next((prioritize.LINK_B.get(f["rule"], "") for f in hits
              if prioritize.LINK_B.get(f["rule"])), "")
    detail = (f"total_gap={(att or {}).get('total_gap', '?')}；"
              f"blocking 偏差 {len(blocking)} 条；规则命中 "
              f"{json.dumps((dsc or {}).get('by_rule', {}), ensure_ascii=False)}；"
              f"证据轮次 generated_at={stamp}")
    if blocking or hits:
        if b:
            return f"缺口 · {b}", detail
        return "失败", detail
    hard = ts.get("hard_leg")
    if hard and hard["status"] != "pass":
        return "未执行", f"难度腿未跑通：{hard['detail']}"
    return "通过", detail


def card_priority(status: str, ev: dict) -> str:
    """优先级：**由分档派生**，不手填。缺口/失败 → 查 priorities.json 里同题项的档；
    查不到 → P1（有实测偏差但没进优先级表，本身就是要看的异常）。通过 → P2（守成）。"""
    if status == "通过":
        return "P2（守成：本卡已由自动化覆盖，只需保持绿）"
    b = status.split("·")[-1].strip() if "·" in status else ""
    for it in (ev["data"].get("priorities", {}) or {}).get("items", []):
        if b and it.get("b_linked") == b:
            return f"{it['priority']}（阻断={it['blocking']}，分数={it['score']}）"
    return "P1（有偏差但未进优先级表——先查 priorities.json 是否缺输入层）"
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""run_real.py —— 真实样本腿：用人工真值对账真实 Word / PDF 文档。

三条口径：

  1. **真值来自 `ground_truth.json`（人工标注）**，不是产物、不是 `expected/` 基线。
     第十七轮的 G9：真值若与被测物同源，结构损失是看不见的。
  2. **幂等率必须恰为 1.0**（`--repeats 2`，逐字节比对两次产物）。确定性转换的幂等
     不是「越高越好」，不等于 1 就是缺陷。
  3. **样本不在仓库里**（`work/real_samples/`，gitignored）。目录不存在时本腿记
     `not_run` + 原因并退 0——「没样本」不是「产品好」，但也算不上产品失败；
     报告首行必须把这件事说出来。

用法：
    .venv/bin/python tests/corpus/real/run_real.py --sample 5 \\
        --json work/qa/real.json --md work/qa/real_sampling.md
"""
from __future__ import annotations

import argparse
import json
import shutil
import sys
import tempfile
from datetime import datetime, timezone
from pathlib import Path

HERE = Path(__file__).resolve().parent
REPO = HERE.parents[2]
SAMPLE_DIR = REPO / "work" / "real_samples"
GT = HERE / "ground_truth.json"
sys.path.insert(0, str(REPO))

from doc2md.errors import Doc2mdError                    # noqa: E402
from tests.qa import attribute, defect_scan, mdscore     # noqa: E402

SUFFIXES = (".pdf", ".docx", ".doc")


def discover(samples_dir: Path = SAMPLE_DIR) -> list[Path]:
    if not samples_dir.is_dir():
        return []
    return sorted(p for p in samples_dir.rglob("*") if p.suffix.lower() in SUFFIXES)


def pick(files: list[Path], n: int) -> list[Path]:
    """确定性抽样：排序后等距取 n 条。重跑取到同一批，结论才可累积。"""
    if n <= 0 or len(files) <= n:
        return list(files)
    stride = len(files) / n
    return [files[int(i * stride)] for i in range(n)]


def run_one(src: Path, *, out_dir: Path, profile: str = "batch",
            repeats: int = 2) -> dict:
    """单份真实样本：转换 → 与人工真值对账 → 缺陷扫描 → 幂等。"""
    rec: dict = {"source": src.name, "kind": src.suffix.lstrip(".").lower(),
                 "bytes": src.stat().st_size}
    gt = json.loads(GT.read_text(encoding="utf-8")) if GT.is_file() else {}
    mine = gt.get(src.name) or {}
    rec["ground_truth"] = "yes" if mine else "no"
    work = out_dir / src.stem
    work.mkdir(parents=True, exist_ok=True)
    sink: dict = {}
    att = attribute.attribute_one(src, out_dir=work, profile=profile,
                                  repeats=repeats, sink=sink)
    rec.update({k: att.get(k) for k in
                ("status", "error_code", "error", "total_gap", "tcolc")})
    rec["by_stage"] = att.get("by_stage", {})
    rec["identity_ok"] = (att.get("identity") or {}).get("ok")
    rec["deviations"] = [d for d in att.get("deviations", [])
                         if d.get("severity") in ("blocking", "major")]
    if att.get("status") != "ok":
        rec["idempotent"] = None
        rec["heading_recall"] = None
        rec["heading_want"] = []
        return rec
    rec["idempotent"] = (att.get("scores") or {}).get("idempotent")
    md = sink.get("md", "")
    # 人工真值只声明了标题**文本**（没有全量层级），所以只算召回、不算层级准确率——
    # 把没有真值的那一维也算进去，就是 G9 的另一种形态。
    want = mine.get("headings") or []
    got = [b.text for b in mdscore.parse_blocks(md) if b.kind == "heading"]
    rec["heading_want"] = want
    rec["heading_got"] = got[:20]
    rec["heading_recall"] = (round(sum(1 for h in want
                                       if any(h in g for g in got)) / len(want), 4)
                             if want else None)
    # 复用同一次转换的产物（sink），不二次转换：真实文档一篇可达数 MB / 数十页
    ctx = defect_scan.ScanCtx(ref_headings=([{"text": h} for h in want] or None),
                              warnings=(att.get("signals") or {}).get("warnings"))
    findings = defect_scan.scan(md, ctx=ctx)
    rec["findings"] = [f.to_dict() for f in findings]
    rec["by_rule"] = {n: sum(1 for f in findings if f.rule == n)
                      for n in defect_scan.RULES}
    return rec


def verdict(records: list[dict]) -> tuple[str, list[str]]:
    """(退出码结论, 原因清单)。幂等 ≠ 1 或 blocking 偏差 ⇒ fail。"""
    why: list[str] = []
    for r in records:
        if r.get("status") == "error":
            why.append(f"{r['source']}: 转换异常 {r.get('error')}")
            continue
        if r.get("idempotent") not in (None, 1.0):
            why.append(f"{r['source']}: 幂等率 {r['idempotent']} ≠ 1.0")
        if any(d.get("severity") == "blocking" for d in r.get("deviations", [])):
            kinds = sorted({d["kind"] for d in r["deviations"]
                            if d.get("severity") == "blocking"})
            why.append(f"{r['source']}: blocking 偏差 {kinds}")
        if r.get("identity_ok") is False:
            why.append(f"{r['source']}: 归因恒等式不成立")
    return ("fail" if why else "pass"), why


def worksheet(records: list[dict], *, fields: int = 3) -> str:
    """人工复核工作表。**人工两栏恒为空**——脚本不预填「通过」。"""
    L = ["# 真实样本人工复核工作表（每篇抽 %d 个字段）" % fields, "",
         "> 自动栏由 `run_real.py` 填；**人工栏必须由人填**，留空即「未复核」，",
         "> 不许由脚本预填、也不许把「自动通过」当成「人工通过」。", "",
         "| 样本 | 字段 | 期望（真值出处） | 自动实测 | 人工复核 | 结论 |",
         "|---|---|---|---|---|---|"]
    for r in records:
        rows = [("标题层级", ", ".join(r.get("heading_want") or []) or "（无人工真值）",
                 f"recall={r.get('heading_recall')}"),
                ("表格列一致率", "同表内列数恒定", f"tcolc={r.get('tcolc')}"),
                ("幂等（两次逐字节）", "1.0", f"{r.get('idempotent')}"),
                ("缺陷规则命中", "0 条 blocking",
                 json.dumps(r.get("by_rule", {}), ensure_ascii=False))]
        for name, want, got in rows[:fields]:
            L.append(f"| {r['source']} | {name} | {want} | {got} |  |  |")
    return "\n".join(L) + "\n"


def not_run_sheet(payload: dict) -> str:
    """无样本时的占位工作表。**只写「未执行 + 原因 + 怎么执行」**，不写任何结论。"""
    return "\n".join([
        "# 真实样本人工复核工作表（未执行）", "",
        f"- 状态：**{payload['status']}**（≠ 通过，也≠ 产品失败）",
        f"- 时间：{payload['generated_at']}",
        f"- 原因：{payload['reason']}",
        "- 怎么执行：把真实文档放进上面那个目录（**不要放进 `tests/`**，"
        "隐私边界红线会拦），然后重跑同一条命令，见 "
        "`tests/corpus/real/README.md`。",
        "- 人工复核栏：本表无行可填；有样本后由 `worksheet()` 生成，人工两栏恒为空。",
        "",
    ])


def main(argv: list[str]) -> int:
    ap = argparse.ArgumentParser(description="Doc2md 真实样本腿")
    ap.add_argument("--samples-dir", default=str(SAMPLE_DIR))
    ap.add_argument("--sample", type=int, default=0, help="抽样份数（0 = 全量）")
    ap.add_argument("--profile", default="batch", choices=sorted(mdscore.PROFILES))
    ap.add_argument("--repeats", type=int, default=2)
    ap.add_argument("--json", default="")
    ap.add_argument("--md", default="")
    a = ap.parse_args(argv)

    sdir = Path(a.samples_dir)
    files = discover(sdir)
    if not files:
        payload = {"status": "not_run", "generated_at": _now(),
                   "samples_dir": str(sdir), "n": 0, "records": [],
                   "reason": f"样本目录不存在或为空：{sdir}（真实文档 gitignored，"
                             "需人工把样本放进去；见 tests/corpus/real/README.md）"}
        _write(payload, not_run_sheet(payload), a)
        print(f"REAL not_run n=0 reason=样本目录不存在（{sdir}）")
        return 0

    chosen = pick(files, a.sample)
    tmp = Path(tempfile.mkdtemp(prefix="d2m-real-"))
    try:
        records = [run_one(p, out_dir=tmp, profile=a.profile, repeats=a.repeats)
                   for p in chosen]
    finally:
        shutil.rmtree(tmp, ignore_errors=True)
    status, why = verdict(records)
    idem = [r["idempotent"] for r in records if r.get("idempotent") is not None]
    rec_h = [r["heading_recall"] for r in records if r.get("heading_recall") is not None]
    payload = {
        "status": status, "generated_at": _now(), "samples_dir": str(sdir),
        "profile": a.profile, "repeats": a.repeats,
        "n_available": len(files), "n": len(records),
        "n_with_ground_truth": sum(1 for r in records if r["ground_truth"] == "yes"),
        "idempotent_min": min(idem) if idem else None,
        "heading_recall_mean": round(sum(rec_h) / len(rec_h), 4) if rec_h else None,
        "failures": why, "records": records,
    }
    _write(payload, worksheet(records), a)
    print(f"REAL {status} n={len(records)}/{len(files)} "
          f"gt={payload['n_with_ground_truth']} "
          f"idem_min={payload['idempotent_min']} "
          f"recall={payload['heading_recall_mean']}")
    for w in why:
        print(f"  FAIL {w}")
    return 0 if status == "pass" else 1


def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


def _write(payload: dict, sheet: str, a: argparse.Namespace) -> None:
    if a.json:
        p = Path(a.json)
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(json.dumps(payload, ensure_ascii=False, indent=2),
                     encoding="utf-8")
    if a.md and sheet:
        p = Path(a.md)
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(sheet, encoding="utf-8")


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```
