**根因泛化（两条同族，值得写进纪律）**：

1. **「重复即噪声」在长文档上会反噬**。重复度信号的前提是「正文不会无缘无故逐页重复同一串」，但 320 页量级的规范/手册类文档恰恰会反复出现同一种短句式；信号的长度上限（`<= 24`）越松，反噬面越大。凡用「跨页重复」判噪声，必须同时给出「这段重复文字是否可能是未写完的正文」的否决项。
2. **红线判据错把源字面量当泄漏时，红线本身成了缺陷**。CH-500 把红线接进生产路径是为了让「交付的产物干净」可证；一周后它的子串判据让「讲 Markdown 的文档」整篇不可用。同一条红线，两种失效方向都真实存在，所以本轮红线写成**双向**：惰性字面量必须放行（活性面）、真泄漏必须仍拒（惰性面）——单向下限的红线守不住判据本身。

**发现路径本身值得登记**：R18-PIPE-2 不是黑盒探针跑出来的，是 **OPT-6 等价性探针的第四面（D4 家具探测窗口敏感性）** 抓到的——本轮为「证明页区间并行安全」而做的逐字节比对，顺手完成了一次结构审计。等价性比对（同一篇文档换个执行形态必须同产物）是本仓库迄今性价比最高的一类测试：它不需要外部真值，却能把「静默丢内容」当场暴露。
